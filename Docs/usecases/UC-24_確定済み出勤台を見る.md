# UC-24 運転会ごとの確定済み出勤台を見る

## 概要
確定・アーカイブされた運転会1回分の出勤台を、確定時点の内容のまま表示する。行路ごと（列車単位の担当者を含む）と、信号・指令シフト枠（区割り・時間帯）を見られる。

## 主アクター
- 閲覧できる利用者（範囲は 要判断事項 Q-24-1 参照）

## 関係アクター
- APIサーバー（閲覧可否の判定）

## トリガー
デスクトップアプリで運転会一覧から確定済みの運転会を選ぶ（または UC-23 の履歴から遷移する）。

## 事前条件
- 利用者がデスクトップアプリにログイン済み（UC-01）
- 対象の運転会の出勤台が確定・アーカイブ済み（UC-21。確定の仕方は**保留**）

## 基本フロー
1. 利用者が確定済み運転会の一覧を開く（A/B、開催日で絞り込み可）。
2. 利用者が運転会を1つ選ぶ。
3. アプリがAPIに確定済み出勤台を要求する。
4. APIが閲覧可否を判定し、アーカイブされた内容を返す。
   - 運転会：名前、A/B、開催日、主催者、共同主催者
   - ダイヤ：アーカイブされたその運転会用のダイヤ名
   - 行路ごとの枠：行路、列車番号のリスト、列車ごとの担当者（途中離脱・途中参加・行路分割を反映）、見習いと指導員の組
   - 信号扱者の枠：区割り（担当駅）、開始・終了時刻、担当者、見習いと指導員の組
   - 指令員の枠：開始・終了時刻、担当者、見習いと指導員の組
5. アプリが出勤台として表示する。担当者は社員番号とハンドルネームで示す。

## 代替フロー
- A1 確定済みの運転会がない：「確定済みの運転会はありません」と表示する。
- A2 退会済みの担当者：記録どおり表示し、「退会済み」と添える。
- A3 確定後に修正された出勤台：確定後の修正の扱いは**保留**（UC-21）のため、修正履歴の表示は扱わない。

## 例外フロー
- E1 ログインセッション切れ・アプリが最低バージョン未満：UC-01 に従う。
- E2 未確定の運転会を指定：本UCの対象外として拒否する（編集中の出勤台は UC-17 / UC-20 で扱う）。
- E3 閲覧権限なし：APIが拒否し、「閲覧権限がありません」と表示する。
- E4 API通信エラー：エラーを表示し、再読み込みを促す。

## 事後条件
- データは変更されない（参照のみ）。

## 扱うデータ（エンティティと主な項目）
| エンティティ | 主な項目 |
| --- | --- |
| 運転会 | 名前、種別（A/B）、開催日、主催者、共同主催者、確定状態、確定日時 |
| アーカイブ済みダイヤ・行路 | ダイヤ名、行路、列車番号のリスト |
| 列車単位の担当記録 | 行路、列車番号、担当者、立場（見習い／正業／指導員） |
| 信号・指令シフト枠 | 役職、区割り（担当駅）、開始・終了時刻、担当者、立場 |
| 社員 | 社員番号、ハンドルネーム、退会済みフラグ |

デフォルトのダイヤ・行路を後から編集しても、表示内容は変わらない（アーカイブ済みのコピーを表示する）。

## 通知
なし。

## 権限チェック
APIで判定する。閲覧できる人の範囲は 要判断事項 Q-24-1 参照。

- UC-11 運転会を作成する / UC-12 運転会用のダイヤ・行路を編集する（コピーとアーカイブ）

## 要件定義書の該当箇所
- 集計：「運転会ごとの確定済み出勤台」
- 行路・ダイヤ：運転会用コピーを確定時にアーカイブする
- 最終状態の保存：確定の仕方は**保留**
- 行路の希望と抽選：「当選者がどの行路に入ったか：必ず公開」
- 権限：出勤記録の閲覧範囲

## 要判断事項
- **Q-24-1 確定済み出勤台を誰が見られるか**
  - 選択肢：(a) ログイン済みの全員が全体を見られる／(b) 全員が見られるが、閲覧範囲外の担当者名を伏せる／(c) 主催者・共同主催者・指導員・事業本部のみ
  - 推奨：(a)。出勤台は運転会の参加者全員で共有する表であり、「当選者がどの行路に入ったか」は必ず公開と定められている。出勤記録の閲覧範囲（本人は自分のみ）は個人の履歴（UC-23）と期限一覧（UC-22）に適用する、と整理するのが自然。
- **Q-24-2 希望・抽選の情報を確定済み出勤台に表示するか**
  - 選択肢：(a) 表示しない（誰がどの枠に入ったかのみ）／(b) その運転会の公開設定（UC-14）に従って希望人数・希望者を表示
  - 推奨：(a)。確定済み出勤台は出勤記録としての閲覧が目的。抽選まわりは保留事項が多い。
- **Q-24-3 A運転会も一覧に含めるか**
  - 選択肢：(a) A/Bとも含める（種別で絞り込み可）／(b) Bのみ
  - 推奨：(a)。A運転会でも出勤台は使い、参加回数も集計するため。
