# 要判断事項一覧

各UCファイルの「要判断事項」を集約したもの。状態は次のとおり。

- **決定**：ユーザー確認済み
- **推奨**：Agentの推奨案。未確認
- **不要**：ほかの決定によって論点がなくなったもの
