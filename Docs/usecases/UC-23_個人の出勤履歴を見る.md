# UC-23 個人の出勤履歴を見る

## 概要
1人の出勤履歴（どの運転会で、どのダイヤの何列車を担当したか、または信号の区割り・時間帯、指令の時間帯）を一覧表示する。閲覧できる範囲はAPIが利用者のロールで判定する。

## 主アクター
- 本人（自分の履歴）
- 指導運転士
- 輸送指導
- 事業本部（管理者）

## 関係アクター
- APIサーバー（閲覧範囲の判定）

## トリガー
- 本人が自分の出勤履歴画面を開く。
- 指導員・管理者が対象者を選んで出勤履歴画面を開く（期限一覧 UC-22 からの遷移、または社員番号・ハンドルネームでの検索。検索方法は 要判断事項 Q-23-4 参照）。

## 事前条件
- 利用者がデスクトップアプリにログイン済み（UC-01）
- 対象者が社員として登録されている（社員番号が発番済み）

## 基本フロー
1. 利用者が対象者を指定して出勤履歴画面を開く（本人の場合は自分が対象）。
2. アプリがAPIに対象者の出勤履歴を要求する。
3. APIが利用者のロールと対象者・各記録の役職から閲覧範囲を判定し、範囲内の記録だけを返す（「権限チェック」参照）。
4. APIが記録ごとに以下を返す。
   - 運転会：名前、A/B、開催日（日付をまたぐ運転会は開始日）
   - 役職と立場：運転士／信号扱者／指令員、見習い・正業・指導員のいずれとして入ったか
   - 運転士の場合：ダイヤ名（その運転会用にアーカイブされたコピー）、行路、担当した列車番号（途中離脱・途中参加・行路分割の場合は担当した列車のみ）
   - 信号扱者の場合：担当した区割り（担当駅）、開始・終了時刻
   - 指令員の場合：開始・終了時刻
   - 一緒に入った見習い／指導員（同じ枠に入った相手）
5. アプリが開催日の新しい順に表示する。

## 代替フロー
- A1 記録なし：「出勤記録はありません」と表示する。
- A2 退会済みの対象者：記録は残っているため表示し、「退会済み」と明示する（閲覧可否は権限チェックに従う）。
- A3 一部の記録だけ範囲外：例えば輸送指導が、運転士と信号扱者の両方の記録を持つ人を見る場合、範囲外の記録の扱いは 要判断事項 Q-23-1 参照。

## 例外フロー
- E1 ログインセッション切れ・アプリが最低バージョン未満：UC-01 に従う。
- E2 閲覧範囲外の対象者を指定：APIが拒否し、「この人の記録を閲覧する権限がありません」と表示する。
- E3 対象者が存在しない：「該当する社員がいません」と表示する。
- E4 API通信エラー：エラーを表示し、再読み込みを促す。

## 事後条件
- データは変更されない（参照のみ）。

## 扱うデータ（エンティティと主な項目）
| エンティティ | 主な項目 |
| --- | --- |
| 社員 | DiscordユーザーID、社員番号、ハンドルネーム、退会済みフラグ |
| 運転会 | 名前、種別（A/B）、開催日、確定状態 |
| アーカイブ済みダイヤ・行路 | ダイヤ名、行路、列車番号のリスト |
| 列車単位の担当記録 | 運転会、行路、列車番号、担当者、立場（見習い／正業／指導員） |
| 信号・指令シフト枠 | 運転会、役職、区割り（担当駅）、開始・終了時刻、担当者、立場 |

表示対象は確定済み（アーカイブ済み）の出勤台に限るかどうかは 要判断事項 Q-23-2 参照。

## 通知
なし。

## 権限チェック
APIで判定する。
- 本人：自分の記録のみ
- 指導運転士：運転士・見習い運転士の記録
- 輸送指導：信号扱者・指令員（各見習い含む）の記録
- 事業本部：すべての記録
- 複数ロールを持つ利用者は、各範囲の和集合
- 指導員として入った記録の閲覧範囲は 要判断事項 Q-23-3 参照

## 関連UC
- UC-21 出勤台を確定しアーカイブする（履歴の元データ）
- UC-20 出勤台を直接書き換える / UC-19 申請を承認・却下する（列車単位・時間帯単位の担当の記録元）
- UC-22 期限一覧を見る
- UC-24 運転会ごとの確定済み出勤台を見る

## 要件定義書の該当箇所
- 集計：「1人の出勤履歴（運転会、ダイヤ、担当した列車、または信号の区割り・時間帯）」
- 権限：出勤記録の閲覧範囲
- UI：「閲覧範囲の判定はAPI側で行う」
- 途中離脱・途中参加：列車ごとに担当者を記録する仕組み
- 信号・指令シフト：開始・終了時刻つきの枠
- 社員番号：退会者の記録を残す

## 要判断事項
- **Q-23-1 範囲外の記録が混ざる人を見たときの扱い**
  - 選択肢：(a) 範囲内の記録だけ表示し、範囲外は存在も見せない／(b) 範囲外は「閲覧権限なし」として件数だけ表示／(c) 範囲内の記録が1件でもあればその人の全記録を表示
  - 推奨：(a)。閲覧範囲は「記録」単位で定義されているため、記録ごとに絞るのが素直。
- **Q-23-2 未確定の運転会の記録を履歴に含めるか**
  - 選択肢：(a) 確定済み（アーカイブ済み）のみ／(b) 未確定も「未確定」と表示して含める
  - 推奨：(a)。集計は最終状態のアーカイブを使う方針。ただし確定の仕方自体は**保留**（UC-21）のため、確定方法の決定後に再確認する。
- **Q-23-3 指導員として入った記録は誰の範囲に入るか**
  - 選択肢：(a) 指導した枠の役職で判定（運転士枠の指導記録は指導運転士・事業本部・本人が見られる）／(b) 指導員の記録は本人と事業本部のみ
  - 推奨：(a)。指導員の回もその役職の出勤記録として数える方針と揃う。
- **Q-23-4 指導員・管理者が対象者を選ぶ方法**
  - 選択肢：(a) 期限一覧（UC-22）からの遷移のみ／(b) (a)＋社員番号・ハンドルネームで検索
  - 推奨：(b)。正業や退会済みの人の履歴も引けるようにするため。
- **Q-23-5 確定済み出勤台へのリンク**
  - 選択肢：(a) 履歴の各行から UC-24 の出勤台へ遷移できる／(b) 遷移しない
  - 推奨：(a)。ただし UC-24 の閲覧可否（Q-24-1）に従う。
