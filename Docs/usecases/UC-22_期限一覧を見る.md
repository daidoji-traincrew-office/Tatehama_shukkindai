# UC-22 期限一覧を見る

## 概要
人ごと・役職ごとに、最終参加日・期限日（リマインド日／再スタート日）・B運転会への参加回数・A運転会への参加回数を一覧表示する。指導員と管理者が、見習いの幽霊部員化の兆候を把握するために使う。

## 主アクター
- 指導運転士
- 輸送指導
- 事業本部（管理者）

## 関係アクター
- APIサーバー（閲覧範囲の判定と集計）
- 本人（自分の行を見られるかは 要判断事項 Q-22-1 参照）

## トリガー
デスクトップアプリで期限一覧画面を開く。

## 事前条件
- 利用者がデスクトップアプリにログイン済み（UC-01）
- 利用者が指導運転士・輸送指導・事業本部のいずれかのロールを持つ
- 最終参加日・期限日がシステムで算出済み（UC-07）

## 基本フロー
1. 利用者が期限一覧画面を開く。
2. アプリがAPIに一覧を要求する。
3. APIが利用者のDiscordロールから閲覧範囲を判定する（「権限チェック」参照）。
4. APIが閲覧範囲内の人×役職ごとに、以下を返す。
   - 社員番号、ハンドルネーム
   - 役職（運転士／信号扱者／指令員）と、見習いか正業か
   - 最終参加日（B運転会の確定済み出勤台にその役職で載った最新の開催日。未参加なら空）
   - 期限の起点（最終参加日、未参加なら見習いロールが付いた日）
   - リマインド日（再スタートの15日前）、再スタート日（起点から暦の上で3ヶ月後）
   - B運転会への参加回数
   - A運転会への参加回数（別の列に回数のみ）
5. アプリが一覧を表示する。期限が近い順など並べ替え・絞り込みができる（要判断事項 Q-22-4 参照）。

## 代替フロー
- A1 該当者なし：閲覧範囲内に対象者がいない場合、空の一覧と「対象者がいません」を表示する。
- A2 正業の行：正業の役職は期限管理の対象外のため、期限日の列は空欄とする（正業の行を一覧に含めるかは 要判断事項 Q-22-2 参照）。
- A3 退会済みの人：期限管理の対象外。一覧に含めるかは 要判断事項 Q-22-3 参照。

## 例外フロー
- E1 ログインセッション切れ・アプリが最低バージョン未満：UC-01 に従い再ログインを求める。
- E2 閲覧権限なし（対象ロールを持たない）：APIが拒否し、アプリは「閲覧権限がありません」と表示する。
- E3 API通信エラー：エラーを表示し、再読み込みを促す。

## 事後条件
- データは変更されない（参照のみ）。

## 扱うデータ（エンティティと主な項目）
| エンティティ | 主な項目 |
| --- | --- |
| 社員 | DiscordユーザーID、社員番号、ハンドルネーム、退会済みフラグ |
| ロール保有状況 | 社員、役職、見習い／正業、見習いロール付与日 |
| 役職別参加状況 | 社員、役職、最終参加日、期限起点、リマインド日、再スタート日 |
| 出勤記録（アーカイブ） | 運転会（A/B・開催日）、社員、役職 ※B/A回数の集計元 |

日付はすべて日本時間。日付をまたぐ運転会は開始日を開催日とする。

## 通知
なし（リマインド・再スタート通知は UC-08 / UC-09）。

## 権限チェック
APIで判定する。
- 指導運転士：運転士・見習い運転士の行
- 輸送指導：信号扱者・指令員（各見習い含む）の行
- 事業本部：すべての行
- 複数ロールを持つ利用者は、各ロールの範囲の和集合

## 関連UC
- UC-07 役職ごとの最終参加日・期限日を算出する（値の算出元）
- UC-08 2.5ヶ月リマインド / UC-09 再スタート（同じ期限日を使う）
- UC-03 退会／再入会の反映
- UC-23 個人の出勤履歴を見る（一覧の行から対象者の履歴へ遷移する想定）

## 要件定義書の該当箇所
- 集計：「人ごと・役職ごとの最終参加日・期限日・B運転会への参加回数の一覧（A運転会への参加は、別の列に回数だけ出す）」
- 対象運転会：「見習い期限の最終参加日は、B運転会の実際の出勤記録でのみ更新する」
- 見習い期限：起点・暦3ヶ月・15日前リマインド・日本時間
- 権限：出勤記録の閲覧範囲
- 社員番号：退会済みは期限管理の対象外

## 要判断事項
- **Q-22-1 本人は期限一覧（自分の行）を見られるか**
  - 選択肢：(a) 見られない（指導員・管理者のみ）／(b) 自分の行だけ見られる
  - 推奨：(b)。閲覧範囲で「本人：自分の記録のみ」と定められており、見習い本人が自分の期限を知ることは幽霊部員化の防止にも役立つ。
- **Q-22-2 正業の役職の行を一覧に含めるか**
  - 選択肢：(a) 含める（期限日は空欄、最終参加日と回数は表示）／(b) 見習いの行だけ表示／(c) 既定は見習いのみ、切り替えで正業も表示
  - 推奨：(c)。主目的は見習いの期限管理だが、参加回数の一覧としては正業も見たい場面がある。
- **Q-22-3 退会済みの人を一覧に含めるか**
  - 選択肢：(a) 含めない／(b) 含めて「退会済み」と表示／(c) 既定は非表示、切り替えで表示
  - 推奨：(c)。期限管理の対象外だが、記録は残す方針のため参照手段は残したい。
- **Q-22-4 一覧の並べ替え・絞り込み・出力の範囲**
  - 選択肢：(a) 並べ替え・役職での絞り込みのみ／(b) (a)＋CSV出力／(c) 表示のみ（固定順：再スタート日の近い順）
  - 推奨：(a)。グラフや統計は後から追加する方針のため、初版は最小限にする。
- **Q-22-5 B/Aの参加回数の数え方**
  - 選択肢：(a) 運転会1回につき1回（行路分割・途中離脱でも1回）／(b) 担当した枠の数
  - 推奨：(a)。「参加」の定義（出勤台の最終状態に載っていること）と整合する。
- **Q-22-6 指導員として入った回をどの役職の行に数えるか**
  - 選択肢：(a) 指導した枠の役職（例：指導運転士として運転士枠に入ったら運転士の行）／(b) 指導運転士・輸送指導の独立した行を設ける
  - 推奨：(a)。「そのロールの出勤記録・最終参加日として数える」の解釈。算出ロジックは UC-07 と揃えること。
